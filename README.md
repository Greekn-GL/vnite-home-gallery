# vnite-home-gallery
A Vnite plugin that turns your library homepage into a game gallery with a large featured image, a scrollable cover strip, and customizable sorting.
Vnite Home Gallery gives your game library a showcase-style homepage. Select a cover to feature that game, then launch it or open its details directly from the showcase. Sort your library by last played date, your personal rating, or total playtime. You can combine sorting options and switch back to Vnite’s original layout at any time.
